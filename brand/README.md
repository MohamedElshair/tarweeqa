# هوية ترويقة — ملفات اللوجو

## الفكرة
"الطبق المتقسم": طبق فطار مستدير متقسم 3 حصص (الأكل المشترك وتقسيم الحساب) وفوقه بخار (فطار سخن).

## الألوان
| الاسم | الكود | الاستخدام |
|---|---|---|
| طماطم | `#E5432D` | اللون الأساسي، الأيقونة، العناوين الكبيرة |
| طماطم غامق | `#C8331F` | الأزرار والروابط (نص أبيض عليه مقروء) |
| صفار البيض | `#F6B42C` | التنبيهات اللطيفة، التمييز |
| نعناع | `#1F8A70` | "تم الدفع" / "خلصت" / الثقة |
| نعناع فاتح | `#3FB592` | بديل النعناع على الخلفية الغامقة |
| كريمة العيش | `#FFF6E9` | الخلفية |
| بُن | `#2B1D14` | النصوص والوضع الليلي |

## الخط
Baloo Bhaijaan 2 (Google Fonts، رخصة OFL مجانية). النص في ملفات اللوجو متحوّل لأشكال، فمش محتاج الخط يكون متسطب علشان اللوجو يظهر.

## الملفات
- `svg/tarweeqa-logo.svg` اللوجو الكامل على خلفية كريمي — والنسخ: `-transparent` شفاف، `-dark` غامق، `-on-red` على أحمر، `-mono` لون واحد.
- `svg/tarweeqa-mark.svg` العلامة لوحدها.
- `svg/tarweeqa-icon-small.svg` نسخة مبسطة (من غير بخار) للأحجام الصغيرة.
- `svg/tarweeqa-app-icon.svg` أيقونة التطبيق.
- `png/` نفس الحاجات PNG جاهزة للسوشيال والمشاركة، ومعاها صورة المشاركة `og-image` بمقاس 1200×630.
- `favicon/` كل ملفات أيقونة الموقع: ارفعها كلها في جذر الموقع (public/).

## الكود اللي يتحط في `<head>`
```html
<link rel="icon" href="/favicon.ico" sizes="48x48">
<link rel="icon" href="/favicon.svg" type="image/svg+xml">
<link rel="apple-touch-icon" href="/apple-touch-icon.png">
<link rel="manifest" href="/site.webmanifest">
<meta name="theme-color" content="#E5432D">
<meta property="og:title" content="ترويقة">
<meta property="og:description" content="اطلبوا سوا.. وكل واحد يدفع نصيبه">
<meta property="og:image" content="https://tarweaqa.com/og-image.png">
```
(انسخ `png/tarweeqa-og-image-1200x630.png` باسم `og-image.png` في جذر الموقع.)

## قواعد بسيطة
- سيب مسافة فاضية حوالين اللوجو قد نص عرض الطبق على الأقل.
- أصغر من 48 بكسل: استخدم الأيقونة المبسطة بس من غير الكلمة.
- ماتغيّرش ألوان الحصص ولا ترتيبها، وماتمطّش اللوجو.
